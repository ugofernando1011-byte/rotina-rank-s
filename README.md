# 🎮 App de Gamificação de Rotina: Jornada Rank S

Este projeto é um aplicativo de desenvolvimento pessoal projetado para transformar hábitos e metas diárias em uma experiência gamificada. O objetivo principal é acumular pontos de experiência (XP) completando missões cotidianas e evoluir de nível até alcançar a classificação máxima.

## 🚀 Mecânicas do Jogo

### 1. Sistema de Progressão e Níveis (Patentes)
A evolução do usuário é baseada no acúmulo total de XP. Cada nível desbloqueia uma nova classificação:
* **Rank E:** Iniciante (0 - 500 XP)
* **Rank D:** Aprendiz (501 - 1500 XP)
* **Rank C:** Praticante (1501 - 3500 XP)
* **Rank B:** Combatente (3501 - 7000 XP)
* **Rank A:** Elite (7001 - 12000 XP)
* **Rank S:** Mestre da Disciplina (12001+ XP)

### 2. Quadro de Missões Diárias (Daily Quests)
As missões são redefinidas todos os dias. Completá-las dentro da janela de tempo correta garante o bônus de XP:

| Missão | Descrição | Recompensa |
| :--- | :--- | :--- |
| **Despertar de Elite** | Acordar pontualmente às 04:40 AM | +100 XP |
| **Foco Inicial** | Primeira sessão de estudos ou leitura do dia | +50 XP |
| **Circuito de Ferro** | Concluir o circuito planejado de exercícios físicos | +150 XP |
| **Mente Alinhada** | Manter o foco e a organização das tarefas profissionais | +80 XP |
| **Nutrição Perfeita** | Registrar e cumprir as metas de alimentação/marmitas | +50 XP |

### 3. Penalidades e Streak (Combo)
* **Streak Bonus:** Cumprir todas as missões diárias por 5 dias seguidos ativa o modo *Combo*, multiplicando o XP ganho no próximo dia por 1.5x.
* **Quebra de Votos:** Deixar de realizar uma missão essencial sem justificativa consome 50 XP do saldo atual.

## 🛠️ Tecnologias Planejadas
* **Front-end:** Interface moderna, limpa e responsiva utilizando os conceitos de usabilidade do *Material Design*.
* **Lógica e Estrutura:** Análise de dados para cálculo de progresso e persistência das pontuações.
